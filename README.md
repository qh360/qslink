# 曜波 QSLink / QSLink

业余无线电台通联与 QSL 卡片管理软件，支持中文和英文。

## 下载 / Downloads

请前往 [GitHub Releases](https://github.com/qh360/qslink/releases/latest) 下载正式版本、查看更新日志及 SHA-256 校验值。

- Windows x64：安装版与便携版，主程序、安装器、卸载器及附带组件采用 Certum 代码签名。
- macOS Apple Silicon：macOS 13 及以上；当前采用本机临时签名，尚未通过 Apple 公证。
